# Make PDF Fillable
An open source offline tool to add fillable fields to a pdf form.

<br>

<img src="images/image1.png" alt="App screenshot" height="500">
<p>Minimalist UI</p>

<br>

## How to use offline
Download the project folder and place it on your desktop. Then double click the index.html file. The app will open in your browser.
